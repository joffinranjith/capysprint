# CapySprint — Energy-Aware Micro-Sprint Productivity Engine

Built for the **Teens Hack Houston Hackathon (Triple H 2026)** under the **Productivity** theme.

## Key Features
- **Real-Time Energy Check-In:** Match tasks to your cognitive bandwidth (*Low / Foggy*, *Steady Flow*, or *Peak Focus*).
- **Brain-Dump Auto-Slicer:** Converts intimidating to-do dumps into bite-sized 10–20 minute micro-sprints automatically (works offline out of the box, plus optional **Anakin AI** API support).
- **Anti-Procrastination "Slice Smaller" Escape Hatch:** Split any active sprint into two tiny halves with one click when feeling stuck.
- **Momentum & Energy Alignment Analytics:** Tracks daily focus minutes, calculates Energy Match Rate %, visualizes a 5-day streak, and exports a Markdown report.
- **Secret Capybara Easter Egg (*Sir Yuzu's Hot-Spring Zen Mode*):** Tap the footer yuzu leaf 3 times or type `capy` anywhere on the page to summon Sir Yuzu and unlock procedural Web Audio hot-spring waterfall ambience.

## Quick Start
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
